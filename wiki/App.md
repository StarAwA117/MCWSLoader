# Android / Windows App

The app is a thin Flutter shell that loads the existing WebUI. It does not
rewrite the UI, so server-side WebUI updates apply without rebuilding the app.

Source: [`mobile/flutter/`](https://github.com/StarAwA117/MCWSLoader/tree/main/mobile/flutter)

## Requirements

- Flutter **3.32+** / Dart **3.8+** (`flutter_inappwebview` 6.x)
- Android: Android SDK
- Windows: Windows 10/11, Visual Studio 2022 with *Desktop development with C++*,
  and the **WebView2 Runtime**

The repository commits only the Dart sources and `pubspec.yaml`; platform
folders are generated by `flutter create` to avoid Flutter-version conflicts.

## Generate platforms

```bash
cd mobile
flutter create --platforms=android,windows --org com.mcwsloader --project-name mcws_webui app
cp -r flutter/lib app/lib
cp flutter/pubspec.yaml app/pubspec.yaml
cp flutter/analysis_options.yaml app/analysis_options.yaml
cd app
flutter pub get
```

## Android

Add to `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.INTERNET" />

<application
    android:label="MCWSLoader"
    android:usesCleartextTraffic="true"
    ...>
```

`usesCleartextTraffic` is required for `http://<LAN-IP>:50005`. Remove it when
using HTTPS.

```bash
flutter build apk --release
# build/app/outputs/flutter-apk/app-release.apk
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

## Windows

No manifest change is needed. Install the WebView2 Runtime if it is missing.

```bash
flutter build windows --release
# build/windows/x64/runner/Release/
```

The `Release/` folder contains `mcws_webui.exe`, `flutter_windows.dll`, plugin
DLLs and `data/`. Distribute the whole folder or wrap it with Inno Setup/MSIX;
Flutter does not produce a single-file exe by default.

## Connecting

| Situation | Address |
|---|---|
| MCWSLoader on the same phone (Termux) | `http://127.0.0.1:50005` |
| MCWSLoader on a PC, phone on the same LAN | `http://<PC-IP>:50005` |
| Windows + MCWSLoader on the same PC | `http://127.0.0.1:50005` |

Only the server URL is stored; the password is entered in the WebUI. The
WebView keeps the login token in `sessionStorage`, so killing the app may
require logging in again.

## Security

HTTP is plain text. Use HTTPS/VPN when the server is not on a trusted LAN. The
WebSocket approval/IP allowlist rules are documented in [Security](Security).
